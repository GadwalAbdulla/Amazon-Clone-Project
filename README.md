# 🛒 Amazon Clone Project

This project is a **static clone** of the Amazon homepage, created using only **HTML** and **CSS** for educational purposes. It was developed to practice frontend web development skills by replicating a real-world website layout.

---

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- Git & GitHub  
- GitHub Pages (for hosting)

---
